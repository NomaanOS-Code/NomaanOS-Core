## 📌 Architectural Overview

NomaanOS Core acts as a **High-Tech Security Shield & Digital Bodyguard** between autonomous AI agents and local system execution. It decouples user intent from direct system calls, preventing Prompt Injection, Jailbreaks, and malicious payload execution via the **Aegis Protocol**.

## 🔑 Core Security Modules (The Aegis Architecture)

1. **Aegis Brain:** Local-first, offline execution engine preventing WAN data leaks.
2. **Sentinel Proxy:** Strict runtime gatekeeper evaluating commands against regex & semantic threat patterns.
3. **Phoenix Engine:** Self-healing engine restoring corrupted state dynamically.
4. **Process Sandbox & Neural Lock:** Isolated container execution paired with keystroke dynamics authentication.
5. **Forensic Evidence Ledger:** Cryptographically linked append-only audit trail compliant with Section 65B legal standards.
