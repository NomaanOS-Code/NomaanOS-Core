# 🛡️ Security & Vulnerability Disclosure Policy

Security is the primary directive of NomaanOS Core. If you identify a potential logic flaw, security risk, or vulnerability, please adhere to responsible disclosure guidelines.

## Reporting Guidelines
* **DO NOT** create a public issue on GitHub for unpatched vulnerabilities.
* Send encrypted/private report details directly to: `nikki08@duck.com`
* Please include steps to reproduce, expected vs. actual behavior, and proof of concept.

We acknowledge security reports within 48 hours and prioritize responsible patch resolution.
